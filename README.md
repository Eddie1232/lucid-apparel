# LU(ID APPAREL

Mobile storefront frontend for **LU(ID APPAREL** — *Wear Confidence.*

Built from the provided design system: gold `#D4AF37` / ink `#121212`, Playfair Display headings + Poppins body.

## Screens

Splash, Sign In, Create Account, Home (Featured Collection / Categories / Trending), Shop, Product Detail, Cart, Wishlist, Orders, Profile, Settings.

## Stack

- React 19 + Vite
- React Router (hash routing)
- Plain CSS design tokens (no UI framework)
- Inline SVG icons & garment illustrations (no external image dependencies)

## Develop

```bash
npm install
npm run dev      # http://localhost:5173
npm run build
npm run lint
```

The app renders inside a phone frame on desktop and goes full-screen on mobile widths.
